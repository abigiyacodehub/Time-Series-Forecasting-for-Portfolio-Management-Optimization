# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-04

### Added
- Initial release of Time Series Forecasting for Portfolio Management Optimization
- Data acquisition module using Yahoo Finance API
- ARIMA time series forecasting model
- Prophet forecasting model
- LSTM neural network forecasting model
- Ensemble forecasting combining multiple models
- Mean-Variance portfolio optimization
- Black-Litterman portfolio optimization
- Risk Parity portfolio optimization
- Efficient Frontier calculation and visualization
- Comprehensive risk metrics (VaR, CVaR, Drawdown, Sharpe, Sortino, etc.)
- Interactive Streamlit dashboard
- Backtesting engine with transaction costs
- Command-line interface
- Unit tests
- Documentation
